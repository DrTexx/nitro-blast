# nitro-blast
Tool for unattended benchmarking

## Building

### Prerequisites

You must have the following installed on your system to build NiTROBLAST.

- [Git](https://git-scm.com/install/)
- [UV](https://docs.astral.sh/uv/getting-started/installation/)

### Windows

From Git Bash, run

```bash
./build.sh
```

### Linux

```bash
./build.sh
```
